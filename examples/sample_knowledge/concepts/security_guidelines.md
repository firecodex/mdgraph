# Remote Device Security Guidelines

All endpoint devices configured under the [Remote Work Policy](./remote_work_policy.md) must have:
1. Full disk encryption (FileVault or BitLocker)
2. MDM profiling enrolled through the [IT Department](./it_department.md)
3. Zero-trust VPN access
