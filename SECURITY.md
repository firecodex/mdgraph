| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

---

## Reporting a Vulnerability

The MdGraph team takes security seriously. If you discover a vulnerability or potential security flaw, please report it responsibly:

1. **Do NOT report security issues via public GitHub issues.**
2. Send an email to **security@mdgraph.dev** with:
   - A description of the vulnerability and its potential impact.
   - Steps or proof-of-concept script to reproduce the issue.
   - Any suggested mitigations or patches.

### Response Timeline

- **Initial Response**: We will acknowledge receipt of your report within 48 hours.
- **Assessment**: We will evaluate the report and provide an estimated fix timeline within 5 business days.
- **Disclosure**: We will coordinate with you to publish an advisory once a patch is released.
